## Render: сохранение SQLite между рестартами

По умолчанию локальный файл SQLite на Render может теряться при пересоздании инстанса.
Чтобы база не пропадала, храните файл на Persistent Disk.

### 1) Создайте Persistent Disk в Render
- В сервисе бота откройте `Disks`.
- Создайте диск.
- Mount Path укажите, например: `/var/data`.

### 2) Укажите путь к БД через переменную окружения
В `Environment` добавьте одну из переменных:

- Рекомендуется: `DB_PATH=/var/data/bot_database.db`

или

- `RENDER_DISK_PATH=/var/data` (тогда имя файла будет `bot_database.db` автоматически)

### 3) Перезапустите сервис
- Нажмите `Manual Deploy` или `Restart service`.

После запуска бот выведет в логи реальный путь БД (`DB path: ...`).
